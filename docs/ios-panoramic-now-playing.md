# iPhone 全景沉浸播放页

## 目标

把 iPhone 的“沉浸模式”从独立封面卡片改为 Apple Music 式全景播放场景：专辑封面延伸到屏幕顶部和两侧，信息与播放控制悬浮在封面自然过渡出的深色区域上。

## 设计规则

- 仅修改 iPhone 沉浸模式；经典、黑胶、简洁、iPad 和 macOS 布局保持不变。
- 默认进入播放页时先展示全景封面，不自动打开完整歌词。
- 方形专辑封面采用居中裁切覆盖上半屏，并用纵向透明蒙版自然消隐，不直接拼接一块纯色面板。
- 背景使用封面的低清放大副本做全屏模糊延展，再叠加取色渐变：16 × 16 采样后按色相聚类选择主色，单独分析封面下缘来决定控制区表面色。
- 顶部遮罩根据封面上缘亮度自适应，浅色封面会自动增强状态栏对比度；中下部颜色则保持封面本身的冷暖倾向。
- 歌曲标题、歌手、收藏与更多操作放在封面下缘，进度、传输、音量和二级操作按 Apple Music 的纵向节奏排列。
- 歌词与队列继续使用现有入口；打开后回到紧凑标题栏，保证长内容的可读性和操作稳定性。
- 保留不小于 44 pt 的触控区域、VoiceOver 标识、下拉关闭手势与现有播放状态逻辑。
- 场景切换使用可打断、克制的淡入和位移动效；开启“减弱动态效果”时退化为短淡入淡出。

## 验收

- 常见 iPhone 纵向尺寸下，封面无左右留白并与底部取色背景连续过渡。
- 刘海/灵动岛上方与 Home Indicator 下方都由同一张背景连续覆盖，不出现安全区色块或水平接缝。
- 标题、进度条和所有控制不遮挡 Home Indicator，短屏不裁切核心操作。
- 歌词、队列、收藏、更多、AirPlay、拖动进度和音量功能保持可用。
- Swift Package 测试与 iOS 模拟器 Debug 构建通过。
