# 首页「关注歌手的新作」

## 目标

用用户真实关注歌手的近期专辑、EP 和单曲替换首页原有的随机热门歌手货架，让首页内容与账号收藏关系一致。

## 数据与展示规则

- 登录启动时同步关注歌手；关注或取消关注成功后立即刷新该列表。
- 首页最多检查列表前 12 位关注歌手，每位读取最近 3 张专辑，网络请求并发上限为 4。
- 仅保留近两年发布、具有有效发布时间的内容，按发布时间倒序排列并按专辑 ID 去重。
- 首页最多展示 12 项，沿用现有专辑方形卡片，可进入专辑详情或直接播放。
- 新作请求属于二级内容：推荐歌单、雷达与排行榜先显示，新作稍后补入，不阻塞首页主体。
- 未登录、没有关注歌手或近两年没有新作时不显示该货架，不回退到随机热门歌手。
