# AI 猜你喜欢

## 目标

在 Kumone 中增加一个由 DeepSeek 驱动的歌曲发现入口。它根据用户已收藏歌曲的歌名与歌手推断口味，返回可解释的歌曲推荐，并将结果映射回网易云音乐曲库以便直接播放。

## 首版范围

- macOS / iPadOS 侧边栏新增“AI 猜你喜欢”，首页增加功能卡片；iPhone 通过首页卡片进入。
- 用户自行配置 DeepSeek API Key，Key 仅保存到系统钥匙串，不进入源码或 `UserDefaults`。
- 每次随机抽取最多 40 首红心歌曲作为口味样本，不发送账号、Cookie、歌曲 ID 等身份信息。
- 调用 DeepSeek Chat Completions JSON Output，生成口味总结、候选歌名、歌手和推荐理由。
- 并发搜索网易云曲库，对歌名和歌手做归一化匹配；无法可靠匹配的候选不会展示。
- 支持可选的“此刻想听”描述、刷新推荐、播放全部和单曲播放。

## 非目标

- 首版不托管公共 API Key，也不建设代理后端。
- 不把 AI 输出直接当作可播放数据，所有歌曲必须经过网易云曲库校验。
- 不保存或上传用户完整收藏列表与网易云登录凭据。

## 错误与边界

- 未登录、红心歌曲过少、未配置 Key 时展示对应引导。
- DeepSeek HTTP / 鉴权 / 限流错误保留可读信息；响应为空或 JSON 无法解析时提示重试。
- 推荐候选可能不存在或版本不一致；匹配阶段要求歌名与歌手均达到阈值，并去重、排除已收藏歌曲。
